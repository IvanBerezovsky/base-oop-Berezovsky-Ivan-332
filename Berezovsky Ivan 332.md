1. Анализ предметной области

Классы:
1. Book
    Атрибуты:
        ISBN, author, name, state
    Поведение:
        Перестает быть доступной, если ее берет читатель. Становится доступной, если читатель ее возвращает.  
2. User
    Атрибуты:
        ID, takenBooks
    Поведение:
        Берет и возвращает книги.
3. Library
    Атрибуты:
        listOfBooks
    Поведение:
        Показывает список доступных и/или выданых книг

Инварианты:
    1. Книга не может быть одновременно выдана и доступна
    2. Нельзя выдать уже выданную книгу
    3. Нельзя вернуть не выданную книгу
    4. Две книги не могут иметь один и тот же ISBN
    5. Две книги не могут иметь одно и то же название
    6. Два читателя не могут иметь один и тот же ID

@startuml

    - author: string

Вопрос 1. Какие атрибуты Book должны быть неизменяемыми после создания? Почему?
    После создания книги, неизменяемыми должны оставаться атрибуты: ISBN, author и name. Это атрибуты, описывающие не состояние, а саму сущность книги.

Вопрос 2. Где должно храниться состояние «книга выдана / доступна» — в классе Book или в классе Library? Обоснуйте.
    Состояние должно хранится в классе Book. Это состояние, описывающее конкретную книгу, а в библиотеке этих книг много. 
    Если его хранить в Library, то прийдется создавать дополнительное состояние для каждой новой книги.
